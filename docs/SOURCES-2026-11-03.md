## Organization and installation

The existing main repository URL is unchanged:

```text
https://raw.githubusercontent.com/MTG9T4/re-3arabi/main/repo.json
```

Short URL for TV entry: `https://is.gd/mtg343`. Use the full short URL, not `mtg343` alone. Its redirect to the manifest and the resulting 49-provider catalog were verified on 2026-11-03. The original `arb` and `343` codes still point to the upstream owner's repository.

Refresh it in Cloudstream → Settings → Extensions. Install the desired named providers. Extension names now have `[Cartoons]`, `[Movies]`, `[Sports]`, or `[Other]` prefixes; the providers keep their website names in Home/Search.

Optional category-only repository manifests are `repo-cartoons.json`, `repo-movies.json`, `repo-sports.json`, and `repo-tools.json` at the same `main/` URL. Add either the main repository or the category repositories you want; adding both is unnecessary.

For ArabicCartoon, open the extension's settings to sign in on the real website with your own account. The plugin reuses that website session on the device. No account credentials are included in this repository, and restricted pages are not treated as video sources.

## Removed and retained

- **SyriaLive:** removed from all active catalogs and excluded from compilation. Its configured `www.syrlive.com` returned an expired certificate repeatedly; its actual hardcoded catalog, `https://d.syrlive.com/`, also failed TLS. Its implementation remains in source control for repair. Existing installations on a TV can be uninstalled manually.
- **CimaClub:** updated the canonical domain and replaced outdated category shortcuts, including the fixed Ramadan 2025 row. Kept the original provider identity so it updates normally.
- **Redirecting sites:** MyCima, Shahid4u, and TopCinema eventually returned pages when allowed additional redirects. They were retained; that observation is not playback certification.
- **Protected sites:** Cloudflare/HTTP 403 responses were not classified as dead sources.
- **Regional or dynamic services:** Cee and Cinemana timed out here; Viu showed its no-service page. Yacine's configured primary hostname did not resolve, but its implementation also has remote configuration/fallback behavior. These sources were retained as unverified rather than removed on a homepage-only check.
- **API providers:** a 404 at an API root is insufficient evidence that its actual API endpoints no longer work; AnimeRift and other application-backed providers were retained with that limitation.

All 44 inherited configured URLs were checked. Raw observations and retries are in [the reachability audit](audits/source-reachability-2026-11-03.json) and [follow-up checks](audits/source-followup-2026-11-03.json). The audit is explicit about being a URL-level check; not all inherited sources were runtime-tested in Cloudstream.
